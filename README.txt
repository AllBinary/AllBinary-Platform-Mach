                             AllBinary Platform Mach

What is it?

This repository contains code generated by the AllBinary Platform for support in Mach.  
This repo is used to allow developers to skip the Mach code generation step.

What are some example games with this Mach code?

https://allbinary.itch.io (The downloads with "-mach" in the filename are Mach only builds. Currently that only includes nothing. Also the Mach builds are not available on Google Play or other stores.)
